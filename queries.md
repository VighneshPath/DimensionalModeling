# Analytics Queries — Global Library Platform

All queries run against the `gold` schema.

---

## 1. Borrowing Trends

### Monthly borrow count

```sql
SELECT
    bd.year,
    bd.month,
    SUM(f.borrow_count) AS borrow_count
FROM gold.fact_borrow_return f
JOIN gold.dim_date bd ON f.borrow_date_key = bd.date_key
GROUP BY bd.year, bd.month
ORDER BY bd.year, bd.month
```

### Product line wise borrowing trend

> `product_line` (Book / Magazine / Journal) is the genre proxy in the current model.

```sql
SELECT
    p.product_line,
    p.title,
    SUM(f.borrow_count) AS borrow_count
FROM gold.fact_borrow_return f
JOIN gold.dim_product p ON f.product_key = p.product_key
GROUP BY p.product_line, p.title
ORDER BY borrow_count DESC
```

## 2. Inventory Usage and Circulation

> `fact_inventory` has no source data yet — queries are written against the designed schema.

### Books that are always short on (lowest current stock)

```sql
SELECT
    p.title,
    p.product_line,
    SUM(fi.addition_change_count) - SUM(fi.removal_change_count) AS current_stock
FROM gold.fact_inventory fi
JOIN gold.dim_product p ON fi.product_key = p.product_key
GROUP BY p.title, p.product_line
ORDER BY current_stock ASC
```

### Books that are surplus and can be sold (highest current stock)

```sql
SELECT
    p.title,
    p.product_line,
    SUM(fi.addition_change_count) - SUM(fi.removal_change_count) AS current_stock
FROM gold.fact_inventory fi
JOIN gold.dim_product p ON fi.product_key = p.product_key
GROUP BY p.title, p.product_line
ORDER BY current_stock DESC
```

## 3. Fines and Delays

### People that always delay returning books

```sql
SELECT
    m.member_name,
    COUNT(*)              AS late_returns,
    AVG(f.days_late)      AS avg_days_late,
    SUM(f.fine_amount_usd) AS total_fines_usd
FROM gold.fact_borrow_return f
JOIN gold.dim_member m ON f.member_key = m.member_key
WHERE f.days_late > 0
GROUP BY m.member_name
ORDER BY late_returns DESC, avg_days_late DESC
```

### Total revenue generated by fines

```sql
SELECT
    SUM(f.fine_amount_usd) AS total_fine_revenue_usd
FROM gold.fact_borrow_return f
```

## 4. Regional Reading Behaviour

### Product lines mostly read per region

```sql
SELECT
    b.country,
    b.city,
    p.product_line,
    SUM(f.borrow_count) AS borrow_count
FROM gold.fact_borrow_return f
JOIN gold.dim_branch  b ON f.branch_key  = b.branch_key
JOIN gold.dim_product p ON f.product_key = p.product_key
GROUP BY b.country, b.city, p.product_line
ORDER BY b.country, borrow_count DESC
```

### Books most commonly borrowed per region

```sql
SELECT
    b.country,
    p.title,
    SUM(f.borrow_count) AS borrow_count
FROM gold.fact_borrow_return f
JOIN gold.dim_branch  b ON f.branch_key  = b.branch_key
JOIN gold.dim_product p ON f.product_key = p.product_key
GROUP BY b.country, p.title
ORDER BY b.country, borrow_count DESC
```

## 5. Revenue from Fines and Rentals

### Monthly revenue (rental + fines, USD)

```sql
SELECT
    bd.year,
    bd.month,
    SUM(f.fee_usd)                       AS rental_revenue_usd,
    SUM(f.fine_amount_usd)               AS fine_revenue_usd,
    SUM(f.fee_usd + f.fine_amount_usd)   AS total_revenue_usd
FROM gold.fact_borrow_return f
JOIN gold.dim_date bd ON f.borrow_date_key = bd.date_key
GROUP BY bd.year, bd.month
ORDER BY bd.year, bd.month
```

## 6. Currency Normalized Reporting

### Total revenue in first quarter (USD)

```sql
SELECT
    SUM(f.fee_usd + f.fine_amount_usd) AS total_revenue_usd
FROM gold.fact_borrow_return f
JOIN gold.dim_date bd ON f.borrow_date_key = bd.date_key
WHERE bd.quarter = 1
  AND bd.year    = 2026
```

### Per-member revenue breakdown in USD

```sql
SELECT
    m.member_name,
    bd.year,
    bd.quarter,
    SUM(f.fee_usd)                     AS rental_fees_usd,
    SUM(f.fine_amount_usd)             AS fines_usd,
    SUM(f.fee_usd + f.fine_amount_usd) AS total_usd
FROM gold.fact_borrow_return f
JOIN gold.dim_member m  ON f.member_key      = m.member_key
JOIN gold.dim_date   bd ON f.borrow_date_key = bd.date_key
GROUP BY m.member_name, bd.year, bd.quarter
ORDER BY bd.year, bd.quarter, total_usd DESC
```
